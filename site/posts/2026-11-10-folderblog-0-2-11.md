# Posts ordered by date and time

Several posts on the same day now show up in the right order. folderblog 0.2.11 gives every post a time of day, and the home page, archives, tag pages, feeds and podcast list are newest first by it.

<!--more-->

To set the time yourself, write it in `date`: `date: 2026-11-10 09:28`. A post with only a day gets the time it was first committed to git, or else the file's modified time. That time is saved in `dates.toml` the first time the post is published, so later edits never reshuffle the day. The day, and so every address, stays the same.

You can set `timezone = "America/Chicago"` in `blog.toml` so dates without an offset are read in that zone. Without it, folderblog uses the computer's own zone, as before. An unreadable `date` is now a warning when the filename has a date to fall back on.

**Before you update:** `timezone` needs 0.2.11 or newer, so update every machine that builds the blog first. The first build adds a time to `dates.toml` for each post that only had a day; commit that file with your blog. Feeds now show real times instead of midnight, and a few same-day posts may swap places in the feed.

The [full release notes](https://blog.ninepointlabs.com/2026/11/folderblog-0-2-11/) are on the Nine Point Labs blog, and the packages are on the [v0.2.11 release](https://github.com/ninepointlabs/folderblog/releases/tag/v0.2.11). After you install, run `systemctl --user restart folderblog`.
