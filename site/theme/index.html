How it works

Write. Save. That's publishing.

  1. 1

    Write

    Any editor, plain Markdown, saved into ~/Blogs/myblog/posts/. Images can sit beside the post.

  2. 2

    Save

    The background service notices, waits for the burst of saves to settle, and builds the site in a fresh folder.

  3. 3

    It's live

    If every page rendered, it's published: to GitHub Pages, any git branch, or any command like rsync.

Theming

The engine owns your content.
The theme owns every other byte.

folderblog finds your posts, renders Markdown, builds the RSS feed and sitemap, and never slips its own markup into your pages. A theme is a folder of Jinja templates that can produce any layout and any file: pages, a search index, a stylesheet, an image.

To prove it, we gave three coding agents the same blog, its AGENTS.md, and a one-line brief each. None of them needed a change to the engine.

GitHub Pages

Five minutes once. Zero clicks after.

  1. Register a small GitHub App on your own account: Administration, Contents and Pages set to read and write, with Device Flow on.
  2. Install it on your account.
  3. Log in with folderblog login github and a one-time code.
  4. That's it. folderblog new myblog creates the repository and turns on Pages at the first publish.

Logins renew themselves. If one expires or is revoked you get a notification, and anything waiting is published within five minutes of logging back in. Step-by-step guide →

Questions

Good questions

Does folderblog ever change my files?

No. It only reads your posts and pages, so an editor with the file open never complains. Its own state (first-seen dates, the last good build) lives in a hidden .blog/ folder.

What happens if I break something?

The build fails in its fresh folder, the live site stays exactly as it was, and you get a desktop notification with the file and line. folderblog status shows it too. Fix it and the next save publishes.

Do I have to use GitHub?

No. Any git remote works, and so does any command: rsync, rclone, Cloudflare's wrangler, the Netlify CLI. folderblog runs it with the finished site folder.

Can I use my own domain?

Yes. folderblog new example.com --domain example.com sets it up on GitHub Pages and prints the DNS records to add at your registrar.

Comments, analytics, search?

Not built in, on purpose. The theme owns every byte, so a theme can add any of them. The magazine theme above generates its own search index.

macOS or Windows?

Linux for now: packages for Arch, Debian/Ubuntu and Fedora, plus a static x86_64 binary. It's written in Rust, so other platforms are possible.
